2. Giao Diện Ứng Dụng & Phân Quyền (RBAC)

Đầy đủ chế độ Khách hàng (Đặt vé, chọn ghế) và Quản trị viên (Admin Panel)

Customer Portal

Hiển thị danh sách phim tiếng Việt chuẩn Unicode có dấu (ví dụ: "Lật Mặt 7: Một Điều Ước"). Khách hàng có thể chọn suất chiếu, chọn ghế trực quan và thực hiện đặt vé thành công với phản hồi API thời gian thực.

POST /api/bookings -> { movie_id, customer_name, seat_number }

Admin Panel (RBAC)

Phân quyền quản trị viên cho phép thêm mới phim, cập nhật suất chiếu, kiểm soát danh sách khách hàng đặt vé và xóa dữ liệu quản lý an toàn.

GET /api/bookings -> Trả về danh sách chi tiết đơn đặt vé

Đã kiểm tra kết nối nguồn dữ liệu và hiển thị thành công metrics

5. Các Biện Pháp Bảo Mật & Hardening Hệ Thống

Áp dụng đầy đủ các tiêu chuẩn bảo mật theo yêu cầu đồ án

Network Isolation

Cô lập mạng Docker nội bộ (app-net), ngăn truy cập trái phép từ bên ngoài.

Nginx Security Headers

Bổ sung X-Frame-Options, X-Content-Type-Options, X-XSS-Protection.
